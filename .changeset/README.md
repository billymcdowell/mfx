# Changesets

Hello and welcome! This folder has been generated by `@changesets/cli`, and holds changesets created through its workflows.

Each `.md` file here describes pending package releases (semver bumps + changelog summaries). Run `npm run changeset` (or `npx changeset`) from the repo root when your PR should trigger a release after merge.

See [changesets/docs](https://github.com/changesets/changesets/blob/main/docs/intro-to-using-changesets.md).
